# Favicon for game-gorillazz Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give game-gorillazz a favicon derived from the hub's existing card icon, present in both `src/` (source of truth) and `docs/` (the deployed GitHub Pages copy).

**Architecture:** A one-off Python/Pillow snippet generates a single 32×32 PNG from the hub's `game-gorillazz-icon.png`; that PNG is written identically to `src/favicon.png` and `docs/favicon.png`, and a matching `<link rel="icon">` tag is inserted into both `src/index.html` and `docs/index.html`.

**Tech Stack:** Python 3 + Pillow (ad hoc script, not committed — see Global Constraints).

## Global Constraints

- Reuse the hub's exact crop/resize algorithm (spec: "Asset") — convert to RGB, center-crop to a square (`side = min(width, height)`, `left = (width - side) // 2`, `top = (height - side) // 2`), resize to 32×32 with `Image.LANCZOS`, save as PNG.
- `favicon.png` and the `<link rel="icon">` tag go in **both** `src/` and `docs/`, not just `docs/` (spec: "Placement") — the favicon is source-of-truth content, not a deploy-only addition like the game-nav footer.
- No new repo script or tooling is added — this is a one-off change (spec: "Mechanism").
- No automated tests exist in this repo; verification is manual per the spec's "Testing" section.

### Task 1: Generate the favicon PNG

**Files:**
- Create: `src/favicon.png`, `docs/favicon.png` (generated binary, no script committed)

**Interfaces:**
- Produces: a 32×32 PNG file, written directly to both final destinations (`src/favicon.png` and `docs/favicon.png`) — later tasks only verify it, they don't regenerate it.

- [ ] **Step 1: Fetch the source icon and generate both favicons in one command**

Run from the repo root (`game-gorillazz`). The source icon is fetched from its **public URL** — do not assume a local sibling checkout of `freaxnx01.github.io` exists (it won't in a fresh clone or a CI runner); do not write any script file to disk — run this as a single inline command through your shell/bash tool, since writing files outside the repo working directory may be blocked in some environments:

```bash
python3 -c '
from pathlib import Path
from urllib.request import urlretrieve
from PIL import Image

icon_path, _ = urlretrieve("https://freaxnx01.github.io/games/assets/game-gorillazz-icon.png")

with Image.open(icon_path) as img:
    img = img.convert("RGB")
    width, height = img.size
    side = min(width, height)
    left = (width - side) // 2
    top = (height - side) // 2
    cropped = img.crop((left, top, left + side, top + side))
    resized = cropped.resize((32, 32), Image.LANCZOS)

    for subdir in ("src", "docs"):
        out_path = Path(subdir) / "favicon.png"
        resized.save(out_path, format="PNG")
        print(f"wrote {out_path}")
'
```

If `PIL`/Pillow is not installed, install it first: `pip install Pillow` (or `pip install --user Pillow` / `pip install --break-system-packages Pillow` depending on the environment).

Expected output:

```
wrote src/favicon.png
wrote docs/favicon.png
```

- [ ] **Step 2: Verify the two outputs are byte-identical and the right size**

Run from the repo root:

```bash
cmp src/favicon.png docs/favicon.png && echo "IDENTICAL"
python3 -c "from PIL import Image; img = Image.open('src/favicon.png'); print(img.size, img.format)"
```

Expected: `IDENTICAL`, then `(32, 32) PNG`.

- [ ] **Step 3: Commit**

