# Favicon for game-gorillazz Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give game-gorillazz a favicon derived from the hub's existing card icon, present in both `src/` (source of truth) and `docs/` (the deployed GitHub Pages copy).

**Architecture:** A one-off Python/Pillow snippet generates a single 32×32 PNG from the hub's `game-gorillazz-icon.png`; that PNG is written identically to `src/favicon.png` and `docs/favicon.png`, and a matching `<link rel="icon">` tag is inserted into both `src/index.html` and `docs/index.html`.

**Tech Stack:** Python 3 + Pillow (ad hoc script, not committed — see Global Constraints).

## Global Constraints

- Reuse the hub's exact crop/resize algorithm (spec: "Asset") — convert to RGB, center-crop to a square (`side = min(width, height)`, `left = (width - side) // 2`, `top = (height - side) // 2`), resize to 32×32 with `Image.LANCZOS`, save as PNG.
- `favicon.png` and the `<link rel="icon">` tag go in **both** `src/` and `docs/`, not just `docs/` (spec: "Placement") — the favicon is source-of-truth content, not a deploy-only addition like the game-nav footer.
- No new repo script or tooling is added — this is a one-off change (spec: "Mechanism").
- No automated tests exist in this repo; verification is manual per the spec's "Testing" section.

### Task 1: Generate the favicon PNG

**Files:**
- Create: `/tmp/gorillazz-favicon.py` (throwaway generation script, not committed to the repo)

**Interfaces:**
- Produces: a 32×32 PNG file, written directly to both final destinations (`src/favicon.png` and `docs/favicon.png`) by this task's own script — later tasks only verify it, they don't regenerate it.

- [ ] **Step 1: Write the generation script**

```python
# /tmp/gorillazz-favicon.py
from pathlib import Path
from PIL import Image

ICON_PATH = Path.home() / "repos/github/freaxnx01/public/freaxnx01.github.io/games/assets/game-gorillazz-icon.png"
REPO_ROOT = Path.home() / "repos/github/freaxnx01/public/game-gorillazz"

with Image.open(ICON_PATH) as img:
    img = img.convert("RGB")
    width, height = img.size
    side = min(width, height)
    left = (width - side) // 2
    top = (height - side) // 2
    cropped = img.crop((left, top, left + side, top + side))
    resized = cropped.resize((32, 32), Image.LANCZOS)

    for subdir in ("src", "docs"):
        out_path = REPO_ROOT / subdir / "favicon.png"
        resized.save(out_path, format="PNG")
        print(f"wrote {out_path}")
```

- [ ] **Step 2: Run it**

```bash
python3 /tmp/gorillazz-favicon.py
```

Expected output:

```
wrote /home/<user>/repos/github/freaxnx01/public/game-gorillazz/src/favicon.png
wrote /home/<user>/repos/github/freaxnx01/public/game-gorillazz/docs/favicon.png
```

- [ ] **Step 3: Verify the two outputs are byte-identical and the right size**
